Metric definitions and run parameters

Week and day use the simulated calendar; range includes both selected days. Partial periods are clipped to the available run time. Search coverage counts quotes finding at least one eligible driver with a free order slot. Driver utilization divides physical service time (pickup travel, boarding, transport) by online time inside the selection, splitting driver spans exactly; a queued order adds no service time until its own pickup starts. Completions use drop-off time. Chart intervals start at the selection's beginning. Only the run's final interval includes its right endpoint.

Session-to-order is converted sessions / all sessions started in this run, including sessions without supply and those still undecided. Offer acceptance is accepted offers / all offers created in this run, including rejected, expired, canceled, failed-acceptance, and pending offers. Later decisions for sessions or offers from earlier runs remain in the event export but are excluded from these new-cohort ratios. Baseline probabilities describe the reference price and ETA; observed ratios vary with market conditions.
