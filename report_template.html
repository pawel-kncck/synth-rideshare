Metric definitions and run parameters

Search coverage counts searches finding at least one eligible idle driver anywhere on the map. Driver utilization uses total active time divided by total online time within each interval. Active time includes pickup travel, boarding wait, and the trip; considering an offer is idle. Completions are assigned by drop-off time. Intervals start at this run's initial time; the final interval includes events exactly at the run end.
